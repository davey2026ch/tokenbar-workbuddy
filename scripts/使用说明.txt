Tokenbar 使用说明
=================

一、这是什么
  给 WorkBuddy 用的悬浮指标条。它会读本机的 WorkBuddy 日志，把「这个任务有多快、
  用了多少 Token、缓存命中了多少」直接显示在屏幕上，不用去翻聊天记录。
  你在左侧切换任务时，卡片会自动跟着切到那个任务的数据。

二、怎么用
  1. 双击 Tokenbar.exe。卡片会出现在屏幕底部、水平居中，离任务栏约 3 厘米；
     多屏时出现在 WorkBuddy 所在的那一块屏幕上。
     配置是程序自己生成的（第一次运行就有），位置在 %APPDATA%\Tokenbar\，
     不用手动创建，也不会写到 exe 旁边。
  2. 鼠标按住卡片任意位置就能拖动，松手后位置自动记进
     %APPDATA%\Tokenbar\tokenbar.ini，下次打开回到原处。
  3. 鼠标移到卡片上，右边会浮出两个小按钮（不悬浮时那里只是一点留白）：
       上面 ✕  = 退出 Tokenbar
       下面 滑杆 = 打开设置
     也可以在卡片上直接点【右键】打开设置。
  4. 设置是一个**独立窗口**，会自动贴在卡片外面（上面放不下就放下/左右），
     不会挡住卡片。里面可以改：
       · 外观：跟随系统 / 深色 / 浅色
       · 布局：横排（两行） / 竖排（两列），缩略图就是实际样子
       · 跟随 WorkBuddy 显示（切到别的应用自动隐身）
       · 指标：拖动行调整顺序，右侧圆点勾选显示/隐藏，右上角「恢复默认」
     改的时候卡片会立刻跟着变，方便看效果。
  5. 点「确定」保存，点「取消」或直接关窗口则还原成打开前的样子。
  6. 已经隐藏时再双击一次 exe，会把卡片叫出来，不会开第二个。
  7. 有新版本时，卡片正上方会浮出一张提示卡，点一下就能更新（详见第六节）。

三、两行数字分别是什么
  本轮：你最近发的那句话引起的这一整轮（内部可能调用模型很多次，全部算进来）。
       左上角圆点是青色的，说明这一轮还在跑（生成、思考、跑工具都算）；变灰代表这轮结束了。
  累计：当前这个任务从开始到现在的合计。

  首字   首字延迟，越小越好
  耗时   这一轮的墙钟时间（含工具执行）
  速度   输出速度 token/s（已扣除首字等待）
  输入   这一轮累计提交的 prompt token
  输出   这一轮累计生成的 token
  缓存   缓存命中的 token 数 + 命中率；模型不返回缓存字段时显示「—」
         （默认不显示这一项，因为本地模型多半不上报；设置里勾上即可出现）

四、两种布局
  横排：一条横着的两行表格，适合放在屏幕底部。
  竖排：一张小卡片，指标竖着排，本轮/累计两列对照，适合放在屏幕侧边。
  切换后位置会自动保持（靠底就往上长，靠边就往里收），不会跑到屏幕外。

五、切换任务会跟着换吗
  会。你在左侧点开另一个任务，半秒内数字就换过去了。数据来源按顺序找：
    1) 日志里还有这个任务的调用 → 现算，最准；
    2) 日志过期了，但 tokenbar-stats.json 里有它的快照 → 用快照，累计行标「缓存」；
    3) 都没有 → 读该任务的会话记录，把输入/输出/缓存加起来（时间类显示「—」）。
  所以不是只对新任务生效，老任务切回去也能看到当时的数字。

六、自动更新
  每次启动 3 秒后，程序会悄悄去 Gitee 看一眼最新版本（公开接口，不用登录）：
   · 有新版：卡片上方出现「发现新版本 vX.Y.Z」，点一下开始下载（带进度条）；
     下完会先检查文件对不对，然后提示「已下载，重启后生效」。
     点「立即重启」就换到新版；不想现在重启也行，正常关掉 Tokenbar，
     下次打开就是新版。
   · 没有新版、或者没网：什么都不弹，不打扰你。
   · 想手动查：设置窗口最下面「版本」那一行，点「检测更新」；
     查出新版后按钮会变成「更新」，点它就开始下载。
   · 新版文件先叫 Tokenbar.exe.new，等旧程序退出后由一个小助手换上去，
     换完自动删掉——不会出现"替到一半文件坏了"。

七、配置与隐私
  设置保存在 %APPDATA%\Tokenbar\tokenbar.ini（即
  C:\Users\<你的用户名>\AppData\Roaming\Tokenbar\tokenbar.ini），
  纯文本，可以直接改（程序第一次运行会自动生成）。
  想打开这个目录：按 Win + R，输入 %APPDATA%\Tokenbar 回车。
  文件末尾的 [meta] 记着「哪个版本、什么时候打的包」，遇到问题时方便对照。
  主题：system / dark / light
  布局：horizontal / vertical
  同目录的 tokenbar-stats.json 是各任务累计数字的快照，自动生成，删掉不影响使用。
  除了「检查更新」会访问 Gitee，程序只读取本机 WorkBuddy 的日志与会话文件；
  不写注册表、不留后台服务。
  从旧版本升级：如果 exe 旁边还留着老的 tokenbar.ini，第一次启动会复制一份到
  %APPDATA%\Tokenbar\，老文件不动。

八、常见问题
  · 缓存一直显示「—」：本地自建模型通常不上报缓存字段，换成云端模型就有数据。
  · 显示「当前任务还没有 Token 记录」：这个任务还没有任何模型调用，发一句话就会出数字。
  · 累计行后面标了「缓存」：这个任务的日志已经不在了，显示的是上次记录的合计。
  · 卡片不出现：可能是开了「跟随 WorkBuddy」而 WorkBuddy 不在前台；切回
    WorkBuddy，或再双击一次 exe。
  · 多屏时卡片跑到别的屏幕：只在第一次运行（还没记住位置）时自动跟 WorkBuddy
    同屏；之后记住你拖到的位置，想换屏直接拖过去。
  · 首次运行被 SmartScreen 拦：程序还没有受信任的代码签名证书，点
    「更多信息 → 仍要运行」。这不是病毒提示，是微软对"没人见过的程序"的统一提醒。
  · 更新提示一直不出现：可能是没网、或者本来就是最新版；也可以在设置里点「检测更新」看看。
  · 数字看起来很大：输入 token 是一轮里每次模型调用的累加，长任务几十 M 很正常。
