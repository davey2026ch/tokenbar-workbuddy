Tokenbar 界面风格方案

三套候选风格，每套都展示浅色 / 深色两种外观。数据用的是真实场景（含缓存命中率和累计行），方便对比效果。

✓ 标签与数值分层，不再挤在一起 ✓ 右侧按钮独立分区，缓存有值也不重叠 ✓ 数字统一表格数字（等宽对齐） ✓ 每列顶部一个标签，本轮/累计共用，不再重复
方案 A

仪表盘 · 简约克制（推荐）

去掉彩虹线，黑白灰为主、一个青色点缀。每列「小标签 → 大数字 → 灰色累计值」三层结构，列与列之间细分隔线。速度在生成中时用点缀色高亮。信息密度高但一眼能定位。

方案 B

彩色胶囊 · 活泼分区

整个条形变成一颗大胶囊，每个指标是独立彩色小胶囊，颜色区分指标类型（首字青、耗时蓝、速度紫、输入粉、输出橙、缓存灰）。累计值缩成小字跟在主值后面。最活泼，但占宽最大。

设置窗口改了什么：
  • 分组标题改成小号大写灰字，段落感更强
  • 外观分段控件改为圆角胶囊式，选中态浮起
  • 跟随开关收进一张卡片里，说明文字更紧凑
  • 指标行用细分隔线代替大行距，勾选改成圆点（未选是空心圈），数量做成小徽章
  • 确定按钮带一点投影，主次更分明
说明：三套方案里「本轮 / 累计·4 轮」都固定在最左侧只出现一次，每列顶部一个指标名、中间大数字是本轮、下面灰色小字是累计——这就是解决「标签和值挤在一起」和「标签重复」的办法。最右一列和按钮之间始终保留独立分区，缓存有值（含 92% 命中率后缀）也不会顶到关闭/设置按钮。竖排两列版式会跟随你选定的风格做同样的语言。
